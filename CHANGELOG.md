# Changelog

All notable changes to Sarah Rose Costa's portfolio site.

## [2.0.0] — Unreleased

Rebuild from the Warm Sketchbook design.

### Added
- Milestone 7: lightbox on a native `<dialog>` (`js/lightbox.js`). Opens from a gallery tile with the currently filtered tiles as its list; the carousel will open it the same way. Variants from the data: commission (price, description, one Etsy button), logo (a compact card per package, "Commission" button with the package name in hidden text), personal (title and year, no button). Etsy buttons open in a new tab; with no listing link yet they read "Visit the Etsy shop" and go to the shop (`data-shop-url` on the dialog). Closes on Esc, the close button or a backdrop click, and returns focus to the tile. Previous/Next buttons, arrow keys and swipe move through the list and wrap; a live region announces "Title, 5 of 12"; Previous/Next and the counter hide for a single piece. Full images use `srcset` (800/1400), `object-fit: contain`, a tint while loading or missing, and preload their neighbours. Desktop: centred 1040 × 660 panel; below 1024 px: a full-screen sheet with the Etsy button pinned to the bottom. The page behind stops scrolling. Open, close and crossfade animations are left for milestone 10. Also a global `[hidden]` rule.
- Milestone 6: filter chips, built from `offerings.json`: "All" plus one per group that has pieces, each showing "from $X" (the group's lowest price, computed). Real buttons with `aria-pressed` inside `role="group"`; the selected chip is styled from `aria-pressed`. Choosing a chip hides the other groups' tiles (`hidden` on each `<li>`), and a visually hidden live region announces "Showing 4 pieces in Pets". Tiles fade in as they appear. Chips scroll sideways in one row on phones and tablets, and wrap and centre on desktop. New `.visually-hidden` utility.
- Milestone 5: `data/offerings.json` (the seven offerings; descriptions and Etsy links blank until Sarah sends them) and `data/gallery.json` (12 placeholder entries). `main.js` loads both at once and hands them to the new `js/gallery.js`, which draws one tile per entry from a `<template>` in the HTML. Tiles are buttons in a list, labelled "alt. Offering, $price+", tinted by group; 2, 3 and 4 columns at phone, tablet and desktop. Captions sit under the tiles, except on hover-capable screens from 1024 px, where a caption bar slides up on hover or focus as the tile lifts (no lift or slide with reduced motion). A missing image shows the offering name on its tint and logs a warning; a failed data load shows a message linking to the Etsy shop, and a `<noscript>` message covers JavaScript being off. Gallery subline now reads "Choose any piece…" so it suits touch and mouse.
- Milestone 4: hero. Eyebrow label, headline, subline, "Work with me" (primary) and "Visit the Etsy shop" (new `.btn-outline`, new tab) buttons; stacked on phones, side by side from 640 px. Art cluster of three tilted pieces that scales as one shape (percentage positions in a 544 × 440 box), one column until 1024 px and two columns after. Images point at their final paths (`images/hero/hero_01.webp` to `hero_03.webp`); until Sarah's files arrive, each shows its group tint.
- Milestone 3: sticky header. Compact below 820 px (wordmark, "Shop" pill, menu button); full from 820 px (four section links, "Shop on Etsy" with bag icon). Border fades in once the page scrolls past 8 px. Phone menu panel (the menu icon becomes an × while open) that closes on a link tap, Esc (focus returns to the button) or a tap outside. Also site-wide: teal `:focus-visible` ring, smooth anchor scrolling (off with reduced motion), `scroll-margin-top` so sections stop below the header, a reusable `.btn-primary`, new tokens `--header-h` and `--text-menu`, and the first JavaScript (`js/main.js`, `js/nav.js`). Etsy links open in a new tab.
- Milestone 2: `css/tokens.css` with every design token from the spec (text sizes in `rem`, scaling smoothly with `clamp()` from 390 to 1280 px), and `css/styles.css` with base styles: paper background, ink text, Fraunces and Nunito from Google Fonts, `h1`/`h2` sizes, gutters, section padding, a 1280 px centred content column, and a skip link hidden until focused. Checked at 320, 390, 768, 1280 and 1600 px.
- Milestone 1: bare `index.html` with all eight sections and their anchors (`#gallery`, `#more-work`, `#about`, `#faq`, `#contact`), landmarks, one `<h1>`, a skip link, and placeholder text. Sarah's missing content is marked `[Placeholder: …]`; parts later milestones build are marked with HTML comments. No CSS or JS yet. GitHub Pages was already on (from `main`).
- `docs/SPEC.md` build spec, `docs/BRIEF.md` decisions, `docs/design/` mockups
- `CLAUDE.md` project instructions for Claude Code

### Removed
- The v1 site (`index.html`) and its guides (`DEPLOYMENT-GUIDE.md`, `IMAGE-GUIDE.md`, `QUICK-START.md`). v1 is kept in git history; its last commit is `4bfa10f`, and its own changelog runs through version 1.2.1.
